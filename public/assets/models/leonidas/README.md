# Leonidas 3D

The production character comes from CGTrader model `6822740`, supplied by the
project owner under the model's Royalty Free License (no AI).

- Source: https://www.cgtrader.com/free-3d-models/character/fantasy-character/spartan-warrior-with-shield-rigged
- `leonidas-spartan-rigged.fbx`: humanoid rig used by Three.js.
- `leonidas-spartan.glb`: static visual fallback.
- `leonidas-shield.glb`: separate shield asset.
- `leonidas-spartan-color.webp`: optimized diffuse texture for the rig.
- `leonidas-spartan-normal.webp`: optimized normal map for the rig.
