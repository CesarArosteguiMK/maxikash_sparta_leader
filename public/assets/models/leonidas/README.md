# Leonidas 3D

The active character is `leonidas-spartan-free.glb`, downloaded by the project
owner from the following Sketchfab model:

- Model: Rigged for UE4 - Spartan - free
- Author: Andy Woodhead
- Source: https://sketchfab.com/3d-models/rigged-for-ue4-spartan-free-666f485199db43488b14035f2a3840bf
- License: Creative Commons Attribution (CC BY)

The GLB contains the body, shield, sword, materials and humanoid skeleton in a
single asset. This avoids moving a separate shield independently from the arm.

Sparta applies its own in-app material palette at runtime: bronze helmet and
greaves, crimson cloth, tempered steel and a bronze shield. The original sword
is hidden in favor of the custom Three.js spear.

`leonidas-spartan.glb` remains as a visual fallback only.
