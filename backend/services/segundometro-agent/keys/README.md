# Llave SSH del agente (local)

Coloque aquí la clave **OpenSSH** que usa el agente, por defecto:

- `jesusssh4.unknown`

Este archivo **no debe subirse a Git**. La carpeta está en `.gitignore` del raíz del proyecto (`keys/*` con excepción de `.gitkeep` y este `README.md`).

En cada máquina o servidor: copie la llave a mano con permisos adecuados.
